# Ajwaa Seating – demo

Interactive Arabic demo of wedding seating for Ajwaa invitations, using sample data for a fictional wedding (Youssef & Laila).

- **`#planner` – ترتيب القاعة:** drag (or tap) families who confirmed their RSVP onto tables, see seats left per table, and auto-arrange the rest by family side.
- **`#guest` – تجربة الضيف:** a guest types their name, scratches a card to reveal their table, and a mini map shows the way from the door.

Single static file (`index.html`), no build step. Seating changes are saved only in the visitor's own browser, so every visitor gets a clean demo.
